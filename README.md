# Photo Booth

A virtual digital-camera photo booth built with React and Vite.

## Getting started

Install Node.js 20.19+ or 22.12+, then run:

```sh
cd frontend
npm install
npm run dev
```

Open the local URL printed by Vite.

## Scripts

- `npm run dev` — start the development server.
- `npm run build` — create the production build in `frontend/dist`.
- `npm run preview` — serve the production build locally.

## Project structure

```text
frontend/
  index.html       HTML entry point
  src/main.jsx     React entry point
  src/App.jsx      Main application component
  src/index.css    Global styles
backend/           Reserved for future backend code
```

The starter includes a responsive placeholder screen. Camera access and photo capture are not implemented yet.
